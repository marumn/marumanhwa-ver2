Only give admin access to trusted accounts. This page uses Firebase Storage for image uploads and Firestore for catalog data.

How it works

  1. Create the manhwa once.
  2. For every new release, enter the same Series ID and new chapter number.
  3. Select all chapter page images in order, then upload.
  4. The reader automatically gets the new chapter in its chapter selector.
